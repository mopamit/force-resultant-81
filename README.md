# כוח בתנועה — פריזמה

משחק והדמיה אינטראקטיבית ללימוד שקול כוחות לכיתה ח'. הפרויקט נבנה כאתר סטטי ומתאים לפרסום ישיר באמצעות GitHub Pages.

## הפעלה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. לבדיקת סביבת שרת מקומית:

```bash
python3 -m http.server 8080
```

לאחר מכן פותחים `http://localhost:8080`.

## פרסום ב-GitHub Pages

1. מעלים את כל תוכן התיקייה לשורש מאגר GitHub.
2. נכנסים אל Settings → Pages.
3. בוחרים Deploy from a branch ואת הענף `main`, תיקיית `/ (root)`.

אין צורך בבנייה, חבילות, בסיס נתונים או שרת.

## מבנה הפעילות

- מעבדה חופשית לשינוי ארבעה כוחות ולצפייה בשקול בזמן אמת.
- גרירת וקטורים ישירות באזור ההדמיה או שינוי באמצעות מחוונים נגישים.
- חמישה אתגרים מדורגים, משוב מיידי וניקוד של עד 100 נקודות.
- צלילי הצלחה, שגיאה וסיום, עם אפשרות השתקה הנשמרת בדפדפן.
- התאמה למחשב, טאבלט וטלפון, תמיכה במקלדת והפחתת תנועה לפי הגדרות מערכת.

## בדיקות

```bash
node --check app.js
node tests/smoke.cjs
```
